Batch vs Online (Stochastic) Training

Two identical networks trained side-by-side with different update strategies.

💡

What's the difference?

Batch gradient descent

Computes gradients using all training samples at once, then updates weights once per epoch. Gradients are stable and accurate but each epoch is expensive.

1 update per epoch

Online (stochastic) GD

Updates weights after every single sample, picked in a random order each epoch. Noisier gradients, but more updates per epoch — use a smaller learning rate.

n_samples updates per epoch
