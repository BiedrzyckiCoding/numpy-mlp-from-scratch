How it works

The MLP stores weights as plain NumPy arrays. A forward pass is a series of matrix multiplications and element-wise activations:

z = W @ a_prev + b
a = activation(z) # hidden
output = z_last # linear out

Backpropagation walks backwards through the cached values and applies the chain rule to compute each gradient:

δ = (ŷ − y) / n
dW = δ @ a_prev.T
δ_prev = Wᵀ @ δ ⊙ f′(z)
